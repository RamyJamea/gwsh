Design a modern and friendly UI prototype for a Restaurant Management System for a Turkish dessert restaurant. The system will be used by cashiers and administrators to manage orders, inventory, and sales.

The design should feel warm, clean, and restaurant-themed, using colors inspired by the menu such as beige, dark brown, and cream, with simple typography and clear buttons suitable for a touch screen POS system.

The prototype should include the following screens:

1. Login Screen

Simple login page with two roles:

Admin

Cashier

Include:

Restaurant logo

Username field

Password field

Login button

Style should be minimal and welcoming.
